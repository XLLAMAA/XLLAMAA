## Sobre mí | About me

**ES:** Soy estudiante de cuarto curso de Ingeniería de Software con especialización en Ciberseguridad. Me apasiona el desarrollo de software en todas sus capas, desde sistemas de bajo nivel hasta aplicaciones web. También disfruto creando software que resuelva problemas cotidianos y automatice tareas para facilitar el día a día de las personas. En el ámbito de la seguridad, me interesa entender cómo los atacantes comprometen sistemas y redes, y aplicar ese conocimiento para construir software más resiliente.

**EN:** I'm a fourth-year Software Engineering student specializing in Cybersecurity. I'm passionate about end-to-end software development, from low-level systems to web applications. I also enjoy building software that solves everyday problems and automates tasks to make people's lives easier. On the security side, I'm interested in understanding how attackers compromise systems and networks, and applying that knowledge to build more resilient software.

- **Programación de sistemas:** desarrollo en lenguajes de bajo nivel, gestión de memoria y optimización del rendimiento.

- **Idiomas:** español nativo, inglés con dominio profesional.
